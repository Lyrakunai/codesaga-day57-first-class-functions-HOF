## 🧠 What I Learned
- Functions can be assigned, passed, stored, and returned.
- `function` refers to a function; `function()` calls it.
- A Higher-Order Function accepts a function as an argument or returns a function.
- One reusable mechanism can execute different behaviors.
- Predicate functions can return `True` or `False`.
- A function without an explicit `return` returns `None`.
- `print()` displays output; `return` sends a value to the caller.
- Dictionary `.values()` gives values, while `.items()` gives key-value pairs.
- Reassigning a dictionary entry does not automatically change a separate variable holding an earlier function reference.
